# PLAT-52090 — [FE] Profile Expiry Soon
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-52094]]
> **Related:** [[PLAT-52094]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-52090

## Summary

This frontend story implements a Passport Expiry Soon warning for passenger profiles whose passport expiry date is exactly 7 months (~210 days) from the current system date. The warning is calculated using exact remaining days between the current system date and the passport expiry date (1 month = 30 days). It must appear on the Passenger List (Save Passenger Data) and Passenger Detail page, and automatically disappear when the expiry date no longer meets the criteria.

## Key Points

- Warning triggers when remaining passport validity reaches exactly 7 months (~210 days) before the passport expiry date.
- Calculation uses exact remaining days between current system date and passport expiry date (1 month = 30 days).
- Warning must automatically disappear if the expiry date no longer meets the criteria.
- Warning must be displayed on Passenger List (Save Passenger Data) and Passenger Detail page.

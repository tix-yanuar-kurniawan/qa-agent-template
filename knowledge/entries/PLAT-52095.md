# PLAT-52095 — Automated Cleanup Unused Profiles
> **Related:** [[PLAT-53354]] · [[PLAT-53353]] · [[PLAT-53352]] · [[PLAT-53350]] · [[PLAT-54350]] · [[PLAT-55153]] · [[PLAT-52876]] · [[PLAT-52096]]

## PRD Summary
Automated system to scan and delete unused passenger profiles belonging to B2C users with >100 secondary profiles. Profiles must be inactive (>18 months old, no paid transactions in 24 months). System performs soft delete first, then hard delete after 1 day. Push notifications inform affected users, and a nudge on the Saved Passenger Data page informs all users about the policy.

## Key Learnings
- Previous manual deletion had issues: included non-B2C, primary profiles, wrong transaction date filter, missing 18-month creation filter
- BigQuery V2 query uses dim_account_profile instead of galaxy_cdc_mysql.members_profile_b2c for deletion check
- Account must have only 1 profile type (B2C only, no corporate mix) to be eligible
- The k8s cronjob triggers DELETE /profiles/unused which processes asynchronously
- Push notification uses template code: member_automate_profile_cleanup
- Config key UNUSED_PROFILE controls the information display on Saved Passenger Data page
- Hard delete query: DELETE FROM members_profile_b2c where isActive = 0 AND deletedAt < CURDATE() AND isPrimary=0

# PLAT-52094 — Profile Expiry Soon
> **Related:** [[PLAT-53539]] · [[PLAT-52846]] · [[PLAT-52093]] · [[PLAT-52092]] · [[PLAT-52091]] · [[PLAT-52090]]

## PRD Summary
This feature introduces a warning and notification system for passenger profiles with passports nearing expiration. A warning is displayed in the Passenger List and Detail pages when a passport is within 7 months of expiry. An automated push notification is triggered exactly 7 months (210 days) before expiry to prompt users to renew.

## Figma Design Summary
The design shows a push notification for iOS with the title "[Passenger Name]'s passport expires soon ⏳" and a body text advising renewal. It includes the app icon and follows standard iOS notification patterns.

## Key Learnings
- The "7 months" requirement is specifically defined as exactly 210 days (30 days/month).
- Notifications must be personalized with the passenger's first name.
- The warning should automatically disappear if the expiry date is updated or no longer meets the criteria.

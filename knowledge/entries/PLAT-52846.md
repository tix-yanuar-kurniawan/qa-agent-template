# PLAT-52846 — [BE] Profile Expiry Soon
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-52094]]
> **Related:** [[PLAT-52094]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-52846

## Summary

This backend story implements Passport Expiry Soon warnings and notifications for passenger profiles whose passport expiry date is exactly 7 months (~210 days) from the current system date. Warnings appear on the Passenger List (Save Passenger Data) and Passenger Detail page and disappear automatically when criteria are no longer met. It also sends automatic expiry-soon notifications including the passenger's first name, with CTA redirecting to the Passenger List Page.

## Key Points

- Warning triggers when passport remaining validity reaches exactly 7 months (~210 days) before expiry (1 month = 30 days).
- Warning displayed on Passenger List (Save Passenger Data) and Passenger Detail page; disappears when expiry date no longer meets criteria.
- Expiry Soon Notification sent automatically when passport will expire in exactly 7 months (~210 days) from current system date.
- Notification must include passenger's first name and clearly indicate passport is expiring soon.
- Notification triggered only for still-valid passports expiring at exactly 7 months; each passenger profile triggers its own notification.
- CTA redirects users to the Passenger List Page.

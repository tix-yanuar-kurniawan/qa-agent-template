# PLAT-53387 — Disabling Points Redemption & Earning for Transaction from specific affiliate partners
> **Related:** [[PLAT-53384]] · [[PLAT-53383]] · [[PLAT-53497]] · [[PLAT-53931]]

## PRD Summary

Extends the existing TikTok points-disabling logic to affiliate partners.
Transactions from specified affiliate partners (identified by tag_aff_id)
have both points earning and redemption disabled. Earning is silently blocked
at the BE level for all product types (HOTEL, FLIGHT, EVENT, CAR,
AIRPORT_TRANSFER). Redemption shows 0 usable points with disabled toggle and a
customized tooltip (EN/ID). Subsidy, promo/cashback/IPC, and status points
remain unaffected. Cobrand users continue earning normally (double/triple).

# PLAT-54039 — [BE] Status Points Mapping for ULP Tier Progress History
> **Related:** [[PLAT-53387]]

## PRD Summary

Replaces the Status Points workaround with direct vertical earning point types (FLIGHT_PAID, HOTEL_PAID) for tier progress. Normal transactions earn full reward points and full GBV; transactions using Tiket Points, Promo Codes, or Gift Vouchers earn minimal reward (1 point) but still send full GBV and transaction count for tier progress.

## Key Learnings

- Two distinct scenarios (normal vs discounted) with the same point type mapping but different reward amounts
- GBV is always the full transaction amount after deduction regardless of discount usage
- Transaction count always increments by 1 regardless of payment method
- The key behavioral difference is only in the reward point amount (full vs minimal)

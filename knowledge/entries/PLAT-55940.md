# PLAT-55940 — [BE] Admin got many error gateway when open and search data on UMP dashboard
> **Type:** Defect · **Status:** Done · **Priority:** High · **Parent:** [[PLAT-55686]]
> **Related:** [[PLAT-55686]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-55940

## Summary

Admins encounter gateway errors when opening and searching data on the UMP dashboard. Several admin API endpoints for WhatsApp and SMS templates return HTTP 504 or 503 gateway errors for the TIKET entity on the test environment.

## Key Points

- 504 gateway errors on: `GET /api/v1/admin/whatsapp/templates?page=1&entity=TIKET` and `GET /api/v1/admin/sms/templates?page=1&entity=TIKET`.
- 503 gateway errors on: `GET /api/v1/admin/sms/templates?page=1&query=staging&entity=TIKET`, `GET /api/v1/admin/sms/templates/failover_test_staging_utility_transactional_v1?entity=TIKET`, and `GET /api/v1/admin/whatsapp/templates?page=1&entity=TIKET`.
- All affected endpoints use base path `https://account.test.bliblitiket.dev/dash-gateway/gks-ump-go-be/`.
- Slack reference: https://tiket.slack.com/archives/C0963SW2FD4/p1780477045032759

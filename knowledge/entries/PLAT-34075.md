# PLAT-34075 — [MVP] Tiket Mission
> **Source:** Jira Epic · Confluence PRD · Figma (linked) · **Jira:** https://borobudur.atlassian.net/browse/PLAT-34075
> **Related:** [[PLAT-45655]] · [[PLAT-56234]] · [[PLAT-53961]] · [[PLAT-38061]] · [[LoyaltyMissionSlugProgressGET]]

## Summary
Tiket Mission (MVP) introduces engaging, configurable loyalty tasks so users complete purchases that meet mission requirements, track progress (stamps / GBV), and claim rewards. The epic (`PLAT-34075`, Platform - Eiffel, status **Done**) covers consumer Mission Landing Page flows (enrollment, progress, completion, claim), BE mission services (configuration, rewards integration, enrollment, progress, comms), and FE integrations including page-module webview and trackers. Admin Mission Dashboard was explicitly **out of scope** for this MVP and was delivered later under [[PLAT-45655]].

## Key Points
- **Goal:** boost engagement/retention via missions as a loyalty USP; primary metrics = enrollments, transactions/user, net rev/user.
- **Glossary:** Mission = task(s) to earn a reward; room nights = rooms × nights per order; progress = eligible completed purchase; completed = all progress done and eligible for reward; multi-enroll = re-enroll while mission active; rewards quota = claimable reward count.
- **Mission types (MVP schemes):** stamp-based (Order ID / Room Night) and GBV accumulation (GBV was listed under out-of-scope in an early PRD cut, but child stories and later dashboard work treat GBV as a first-class type — treat dashboard/GBV as post-MVP where noted).
- **Enrollment:** slide-to-enroll on mission detail; enrollment not required to *earn* progress from eligible purchases, but required to *see* progress on the detail page and to *claim* rewards. Unenrolled progress can still be stored.
- **Progress:** stamp when order is paid and trip completed; over-progress allowed within mission period; refunds/cancellations handled via order/refund Kafka.
- **Rewards:** integrate Promo (GV/promo inject) and ULP points; claim flow when mission completed and quota available.
- **Multi-enroll:** optional; when On, admin sets max enroll count (default 2 including first); Off = single enroll.
- **Comms:** Email + PN for enrolled and unenrolled users (first progress, 50%/75% progress, completed, unenrolled progress/completed). Skip progress PN/email when mission completes in a single order.
- **Public URL:** `tiket.com/mission/[mission_slug]`; CTA URLs must stay on tiket.com domain.
- **Out of scope (MVP PRD):** Pending Progress, GBV accumulation (early), Dashboard, specific user segments (tier/cities), specific brands, multi-currency.
- **Dependencies:** Message (PN templates); Order (General Search with optional account ID; Kafka for orders/refunds). Related BE work: [[PLAT-38061]] Generic Search modification.
- **Delivery:** 22 child stories (BE/FE/QA) all Done; labels `Loyalty`, `P0-Dev-Execution`, `qa_64`, `qa_65`. Target release originally Q1/Q2 2025.

### PRD — `[PRD] Tiket Mission (MVP)`
- **Background:** retention in competitive ID OTA market; Mission as engaging tasks + rewards on top of existing loyalty benefits.
- **Success metrics:** # enrollments; uplift transactions/user; uplift net rev/user.
- **Projected impact (example scheme buy 10 room nights → 1 free):** ~IDR 6B additional GBV; ~1.1k room-night transactions/year.
- **Admin configuration (MVP intent, later productized in dashboard):** banner ratios, name, period (open-ended if no end date), nudge/low-quota (&lt;10%), progress texts (6 states, max 25 chars), stamp icons, colors (label/section/stroke/progress), How to Join (min 3 steps), FAQ (up to 10), TnC, multi-enroll, CTA URL, slug, notification toggles.
- **Rewards integration:** Promo + ULP points.
- **Notifications:** PN templates `mission_progress`, `mission_completed`, `mission_unenrolled_progress`, plus email counterparts for enrolled/unenrolled journeys.
- **Out of scope:** Pending Progress; GBV accumulation; Dashboard; segment/brand/multi-currency targeting.
- **Timeline (PRD):** Design Sprint 60 → Solution 61 → Dev 62+; expectation Q1 2025 (epic later completed).

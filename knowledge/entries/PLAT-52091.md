# PLAT-52091 — [BE] Solutioning for Profile Expiry Soon
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-52094]]
> **Related:** [[PLAT-52094]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-52091

## Summary

This backend solutioning story defines how to warn users about passenger profiles whose passports may expire soon, enabling the tech team to evaluate feature feasibility. It covers displaying a Passport Expiry Soon warning when remaining validity is exactly 7 months (~210 days) on the Passenger List and Passenger Detail page, plus automatically sending expiry-soon notifications to users. Notifications must include the passenger's first name, indicate the passport is expiring soon, and redirect via CTA to the Passenger List Page.

## Key Points

- Warning triggers when passport remaining validity reaches exactly 7 months (~210 days) before expiry (1 month = 30 days).
- Warning appears on Passenger List (Save Passenger Data) and Passenger Detail page; disappears automatically when criteria no longer met.
- Expiry Soon Notification sent automatically when a passenger's passport will expire in exactly 7 months (~210 days) from current system date.
- Notification must include the passenger's first name and clearly indicate the passport is expiring soon.
- Notification triggered only for passports still valid and expiring at exactly 7 months; each passenger profile triggers its own notification.
- CTA redirects users to the Passenger List Page.

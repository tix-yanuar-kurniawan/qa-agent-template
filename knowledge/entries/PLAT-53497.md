# PLAT-53497 — [BE] Show user's total points amount when points are disabled/capped
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-53387]]
> **Related:** [[PLAT-53387]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-53497

## Summary

This backend story ensures the payment page points section shows the user's actual balance when points redemption is disabled due to a `meta_id` restriction. When a user with a greater-than-zero points balance views the points section, the system displays "Points user can use" as 0 and "Current points" as the actual user balance reflecting the real-time balance.

## Key Points

- Condition: user has >0 points balance and points redemption is disabled due to `meta_id` restriction.
- Trigger: user views points section on payment page.
- "Points user can use" = 0.
- "Current points" = actual user balance.
- Total points must reflect the real-time user balance.

## Details
### **Given**

* User has a >0 points balance
* Points redemption is **disabled** due to `meta_id` restriction

### **When**

* User views points section in payment page

### **Then**

* The system shows:

    * **"Points user can use" = 0**
    * **"Current points" = actual user balance**

* The total points must reflect the **real-time user balance**

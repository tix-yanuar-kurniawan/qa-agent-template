# PLAT-59830 — [FE] Adapt dynamic widget on webview pages
> **Related:** [[PLAT-59832]] · [[PLAT-59831]] · [[GRA-7349]] · [[PLAT-56702]] · [[PLAT-56247]] · [[PLAT-55268]] · [[PLAT-57973]] · [[PLAT-34075]]

## PRD Summary

Discovery's mission dynamic widget (live stamp count, mission state, CTA) already renders on **native app** pages. Webview surfaces (campaign landings, deeplinks, CRM/push/social) showed a static or empty slot because the widget needed native-only rendering. Webview support for `DYNAMIC_WIDGET` now exists ([[GRA-7349]]), so this epic adapts the **existing** widget onto webview with the **same** dashboard config, display (including 4:3 and the >10-stamp 5+last rule), and CTA matrix — not a redesign. Child stories: [[PLAT-59832]] `[FE]` holds the ACs (platform Responsive); [[PLAT-59831]] `[FE]` Tech Assessment has no testable ACs. Widget URL already documented in [[PLAT-56702]]: `/<locale>/dynamic-content-module/mission/<slug>`.

## Key Learnings
- **No Figma on this epic or its children.** Related [[GRA-7349]] Confluence PRD links Mission Page and Homepage Dashboard Figma files. Labels and transitions are defined only by [[PLAT-59832]] and the CTA names already in [[PLAT-56247]].
- **[[GRA-7349]] scope is separate.** Concurrent 5 modules, impression/click tracking, dashboard URL field, payment-success *shell* enablement stay on Discovery. This epic is Loyalty widget *content* once a webview can host it. Host page URL is `UNKNOWN` — GRA-7349 names payment-success and vertical landings; this epic does not.
- **[[PLAT-55268]] "webview → native click-through is unsupported" is historical.** This epic (plus GRA-7349 native-component support) is the change that makes bottom sheets and UNM login from the widget expected on webview.
- **CTA matrix is copied, not extended.** Eight user states from [[PLAT-59832]] match [[PLAT-56247]]. Two enroll sheets stay split (0 stamps vs ≥1 stamps / Success Enroll vs Success Enroll + Progress).
- **Claim-from-widget is a convenience.** User can still claim from the mission page (one extra tap).
- **Panel path.** Panel writes go through `/admin/care/loyalty/mission-config`; exact widget-field form path is UNKNOWN.
- **Related prior knowledge:** [[PLAT-56702]] widget URL; [[PLAT-56247]] sheet names and CTA matrix; [[PLAT-57973]] guest/enroll behaviour; [[PLAT-55268]] webview-native caveat.

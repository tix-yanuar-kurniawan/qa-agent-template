# PLAT-45655 — Tiket Mission Dashboard
> **Source:** Jira Epic · Figma (linked) · **Jira:** https://borobudur.atlassian.net/browse/PLAT-45655
> **Related:** [[PLAT-34075]] · [[PLAT-56234]] · [[PLAT-53961]]

## Summary
Loyalty missions were previously configured manually by Backend, creating a bottleneck for campaign creation. This epic delivers a **Mission Dashboard in Admin Care** so Campaign Managers can create, edit, preview, and manage loyalty missions end-to-end (list, search, multi-step creation, draft/publish, live preview, page module, and communications). Epic `PLAT-45655` (Platform - Eiffel, status **Done**) is the admin counterpart to the consumer MVP [[PLAT-34075]].

## Key Points
- **Objective:** empower business users to autonomously create/edit/manage missions; reduce BE manual work; accelerate campaign launches.
- **Mission List:** tabs All / Active / Ended / Scheduled / Draft; filter by mission type (Order ID, Room Night, GBV); columns include header image, name, slug, reward, start/end (UTC+07:00), status, last updated (datetime + admin email), view detail. Privilege ID **4024**.
- **Status rules:** Active = now ∈ [start, end); Ended = now &gt; end; Scheduled = now &lt; start; Draft = saved draft not yet active/scheduled.
- **Search:** real-time partial match on mission name.
- **Create Mission — Scheme (step 1):** mandatory name, slug (`char-char-...`), label text, start/end, rewards claim deadline; optional dynamic end period + days; optional user segment (Amplitude Cohort / Experiment / CDP). Mission type Order ID/Room Night (stamps, max 20, free stamps, verticals, payment method, min amount) or GBV (amount, verticals, payment). Room Night verticals limited to Hotel / TixHotel / Homes.
- **Content:** How to Join (up to 4 steps, ID+EN + assets), FAQ (up to 10), TnC (ID+EN), page module code; sticky live preview.
- **Visual:** header images, stamp icons (not-last / last / free / enrolled variants), colors (label, section background top/bottom, border, next-progress stamp); sticky live preview.
- **Page Module (optional toggle):** reward/mission titles, stamp assets, colors; sticky live preview.
  **Caveat for Mission List (2026-08-10):** list cards reuse the page-module shape
  ([[PLAT-56247]] / API Mission List). Leaving this toggle off on a published
  mission produces a broken list card. Interim: keep Page Module **on** for any
  list-visible mission. Planned: section becomes mandatory after a coming-sprint fix.
- **Comms:** email + PN toggles and custom fields (mission name, headers); preview for email templates and PN copy.
- **Edit:** pre-fill all fields; **locked** after publish for mission type, period type, rewards type, stamp/GBV target amount. Start date editable only before start. Changes apply to **new** transactions only; cache ≤ 5 minutes.
- **Preview states:** No progress, On progress, Completed, Hidden enrolled (unenrolled), Free stamp (if configured).
- **Navigation / save:** Cancel exits without new save (draft keeps last draft); Save as draft requires Scheme mandatory fields and only on create; step-forward saves when mandatory fields valid.
- **Platforms:** Panel - dWeb + Backend (+ FE consumer refactor for new mission page component / live preview).
- **Follow-on:** Duplicate mission + Section Background mapping under [[PLAT-56234]].

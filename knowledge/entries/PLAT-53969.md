# PLAT-53969 — [Android] Dynamic Missions in Welcome Rewards
> **Type:** Story · **Status:** Ready Deploy (PROD) · **Priority:** Medium · **Parent:** [[PLAT-53961]]
> **Related:** [[PLAT-53961]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-53969

## Summary
This Android story enables users to see missions in Welcome Rewards and open a specific mission detail page to view and join missions. After a fresh install and onboarding, the user sees the Welcome Rewards Bottom Sheet. The system loads Welcome Rewards configuration based on user source (Campaign ID, UTM Source, or Default) and displays mission modules mapped to Loyalty missions.

## Key Points
- Welcome Rewards configuration is loaded based on user source: Campaign ID, UTM Source, or Default.
- Each mission module must map to a corresponding Loyalty mission via Mission ID; missions not available in Loyalty must not be displayed.
- When logged in, the system automatically sets user eligibility for all missions via Loyalty API using Mission ID and Account ID once required data is available.
- Clicking a mission module CTA redirects to the Mission Detail Page; navigating back returns to Welcome Rewards.
- If not logged in, clicking any mission module redirects to Login/Register; after successful login/register, user returns to Welcome Rewards and eligibility is set once Account ID is available.
- Each Mission Module consists of Mission Icon, Mission Title, Mission Subtext (all from BE Config), and a CTA Button.
- Tracker must be added when user clicks the Mission Module (slide 36).

As a user, I want to see missions in Welcome Rewards and open a specific mission detail page so I can view and join the mission.

**Given** new user has just installed the app (fresh install)

**When** user finishes onboarding

**Then** user will see the Welcome Rewards Bottom Sheet

**Acceptance Criteria:**

1. System loads Welcome Rewards configuration based on user source: Campaign ID, UTM Source, or Default.
2. If the selected configuration contains one or more mission modules and user is logged in:

    * Each mission must be mapped to a corresponding mission in Loyalty using Mission ID.
    * Missions not available in Loyalty must not be displayed.
    * System automatically sets user as eligible for all missions by calling Loyalty API using Mission ID & Account ID once all required data is available.

3. Clicking on button in mission module will redirect user to the Mission Detail Page.
4. If user navigates back from Mission Detail Page, user will return to Welcome Rewards.
5. If user is not logged in:

    * Clicking any mission module will redirect user to Login/Register Page.

6. After successful login/register:

    * User is redirected back to Welcome Rewards.
    * Once Account ID is available, system automatically sets user as eligible for all missions by calling Loyalty API using Mission ID & Account ID.

7. Each Mission Module must consist of:

    * Mission Icon (from BE Config)
    * Mission Title (from BE Config)
    * Mission Subtext (from BE Config)
    * CTA Button

# PLAT-52848 — [Gamification] Top Spender System Development
> **Type:** Epic · **Status:** Done · **Priority:** High
> **Related:** [[PLAT-54035]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-52848

## Summary

This epic revamps the Top Spender Program into a high-engagement gamification platform featuring real-time leaderboard, coin-based rewards, missions, and personalized competition mechanics. The initiative aims to drive increased GBV and user retention by transforming tiket.com into the primary booking platform for informal travel agents, consolidating their spend and increasing platform stickiness.

## Key Points

- Revamps Top Spender Program into a gamification platform with real-time leaderboard, coin-based rewards, missions, and personalized competition mechanics.
- Goals: drive increased GBV and user retention.
- Targets informal travel agents as primary users on tiket.com to consolidate spend and increase platform stickiness.
- Design reference: Figma Top Spender Season 3.0.
- PRD: Top Spender Program Travel Agent Gamification 2.0 (Confluence).

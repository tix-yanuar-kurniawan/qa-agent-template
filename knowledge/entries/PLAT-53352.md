# PLAT-53352 — [Android] Show cleanup information on Saved Passenger Data page
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-52095]]
> **Related:** [[PLAT-52095]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-53352

## Summary

This Android story displays a notice on the Saved Passenger Data page informing users about automated cleanup of unused passenger profiles. When a user opens the Saved Passenger Data page, the system shows a notice that unused profiles may be periodically deleted.

## Key Points

- Display a notice about automated cleanup of unused passenger profiles.
- Trigger: user opens the Saved Passenger Data page.
- Notice informs that unused profiles may be periodically deleted.

# PLAT-59097 — [General] Top Spender Improvement (Challenge and Partner)
> **Related:** [[PLAT-59102]] · [[PLAT-59103]] · [[PLAT-59104]] · [[PLAT-60130]] · [[PLAT-59105]] · [[PLAT-59107]] · [[PLAT-59108]] · [[PLAT-59109]] · [[PLAT-59113]] · [[PLAT-60336]] · [[PLAT-58175]] · [[TOP-SPENDER-V2-PHASE-3]]

## PRD Summary

Moves Top Spender challenges from a Coins-only reward to a multi-reward framework,
and adds richer challenge cards, nudges, a completion popup, a reward history
upgrade, a GV entry point and a partner section.

- **Multi-reward** ([[PLAT-59102]] FE / [[PLAT-59103]] Panel / [[PLAT-59104]] BE / [[PLAT-60130]] Panel UI):
  reward types Top Spender Coins, Blibli Tiket Points, Gift Voucher (mandatory on
  summary card) and Physical Prize (optional). A challenge can hold one or many
  types. Points and GV are injected through **Reward Hub** using a campaign code
  configured per reward in the dashboard (`TS_{mission_name}`, lower case, no
  space). Dashboard reward config: Reward Type, Amount, Position, Quota
  (Unlimited / First N Participants), campaign code for GV and Points.
- **Challenge card** ([[PLAT-59105]]): title (ID/EN), tooltip description (ID/EN),
  progress bar, number-formatted progress value, multi-reward chips, CTA
  (label ID/EN + URL).
- **Nudges** ([[PLAT-59113]]): one nudge per card. Priority: completed/claimable/claimed
  (none) → timed out (none) → Quantity progress → GBV progress → Social proof
  (progress 0, ≥1 claim) → First completer (progress 0, 0 claims, Panel toggle).
- **Completion popup** ([[PLAT-59107]]): lists all rewards; message "first 10" for
  completion rank 1–10, else percentage = completers ÷ total participants × 100,
  rounded (6.5 → 7). CTA / popup tap → Challenge page.
- **Reward history** ([[PLAT-59108]]): summary Coins / Points / GV / Other Bonus;
  Active tab per challenge with name, reward breakdown, finish date; Pending tab
  with amount and activation date; ongoing challenges excluded.
- **GV entry point** ([[PLAT-60336]]): the whole GV component is clickable to
  `/en-id/voucher-box`; count comes from BE; count 0 is shown but not clickable;
  mobile and desktop; login users only.
- **Partner section** ([[PLAT-59109]]): title/subtitle (ID/EN), horizontally
  scrolling partner cards (logo, localized name, reward, CTA indicator) in CMS
  order; tap → bottom sheet with popup title, logo, name, reward, T&C; close via
  X, swipe down, tap outside.

## Figma Design Summary

- Challenge page header "Completed Challenges 2/10", "You've collected" Coins /
  Points / Gift Voucher plus "Other Bonuses: …", then "Ends on <date>" and a
  "Limited rewards" label.
- Cards show reward chips (`+100,000` with coin / points / GV icons, `+Airpod 2`),
  a "Bonus quota: 10" label on quota challenges, a countdown on timed challenges,
  GBV progress as a percentage, a `+20% of Transaction` coin chip, and Claim /
  Claimed states with a "Completed" stamp.
- Popup: "Challenge complete — You get:" reward list, "You're among the 3% who
  completed this challenge", CTA "Complete other challenges".
- History "Your Rewards": Coins / Points / Gift Voucher > summary, Other Bonuses,
  Active / Pending / Refund tabs; challenge entries list every reward type.
- Partner detail opens as a bottom sheet on mobile and a modal ("Extra bonuses
  from partners") on desktop. The partner frames sit on the **landing page**.
- Dashboard reward form: Reward Type*, Coins Amount*, Reward hub campaign code,
  Cancel / Save Reward — the campaign code field is drawn with **Coins** selected.

## Key Learnings

- **Source reconciliation.** [[PLAT-59106]] and [[PLAT-59110]] (Panel twins of the
  card and partner stories) are *Invalid*; [[PLAT-59327]] and [[PLAT-60778]] are
  *Dropped*. No dedicated Panel story covers card text/CTA/tooltip config or
  partner CMS.
- **Copy conflicts between story and Figma**: Quantity nudge "6 more transactions to get the reward."
  vs Figma "7 transactions left to get the bonus."; GBV "…to get the reward." vs
  "…to get the bonus."; popup "You're among the 7% of users who…" vs Figma
  "You're among the 3% who…".
- **Surface conflict:** the partner story says the section is on the Challenge
  page, Figma places it on the landing page.
- **Campaign code field scope conflict:** story says only GV and Points get the
  field, the dashboard design shows it with Coins selected.
- **Undefined terms:** "Total Challenge Participants" vs "Total Users Who Joined
  the Challenge" — the popup denominator depends on it and the PRD never defines
  participant. "Bonus quota: N" could be total or remaining quota.
- **Unspecified behaviours:** card display once a quota is
  exhausted; whether campaign code is mandatory or validated against the
  `TS_{mission_name}` format; editing rewards on a live challenge; Reward Hub
  injection failure handling; partner section empty state; singular nudge copy.
- **Money risks without written AC:** per-reward quota
  independence, double-claim idempotency and concurrent claims at the First N
  boundary — each can over- or under-distribute Points/GV.

# PLAT-53384 — [BE] Restrict points earning for specific affiliate partners
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-53387]]
> **Related:** [[PLAT-53387]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-53384

## Summary

This backend story restricts points earning for transactions with a configured restricted `tag_aff_id`. When payment passes the restricted affiliate ID to Loyalty and payment is successfully completed, the user receives no earning points (including HOTEL_PAID, FLIGHT_PAID, EVENT_PAID, CAR_PAID, AIRPORT_TRANSFER_PAID, and any other earning points). The user remains eligible for subsidy points, promo code/cashback/IPC points, and status points for tier progression. Cobrand users can still receive points as usual (double for usual, triple for payday).

## Key Points

- Trigger: payment passes restricted `tag_aff_id` to Loyalty and payment is successfully completed.
- User receives no earning points: HOTEL_PAID, FLIGHT_PAID, EVENT_PAID, CAR_PAID, AIRPORT_TRANSFER_PAID, and any other earning points.
- User still eligible for: subsidy points (if any), promo code/cashback/IPC points (if available), status points for tier progression.
- BE config: set `tag_aff_id` where points earning will be restricted.
- Cobrand users still receive points as usual (double for usual, triple for payday).

## Details
**GIVEN**

* There have been points earning restrictions set for a specific `tag_aff_id`

**WHEN**

* Payment passes the `tag_aff_id` that has been restricted for earning to Loyalty
* AND the payment is successfully completed

**THEN**
The user should not receive any earning points, including:

* HOTEL_PAID
* FLIGHT_PAID
* EVENT_PAID
* CAR_PAID
* AIRPORT_TRANSFER_PAID
* and any other earning points

**Additional details:**

1. **The user will still be eligible to receive:**

    * Subsidy points (if any)
    * Promo code / cashback / IPC points (if available)
    * Status points for tier progression

2. **In the BE config, we will need to set:**

* `tag_aff_id` name where points earning will be restricted

3. Cobrand users will still be able to receive points as usual

    1. Double for usual
    2. Triple for payday

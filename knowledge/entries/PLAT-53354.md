# PLAT-53354 — [BE] Automated Cleanup Unused Profile
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-52095]]
> **Related:** [[PLAT-52095]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-53354

## Summary

This backend story implements automated cleanup of unused passenger profiles in `members_profile_b2c`. A scheduled job runs every 30 days to identify eligible B2C secondary profiles, soft-deletes them, and hard-deletes them after one day. The system also sends a push notification before cleanup and displays a notice on the Saved Passenger Data page.

## Key Points

- Scheduled job runs every 30 days to identify unused profiles in `members_profile_b2c`.
- Eligibility: B2C account with more than 100 secondary profiles; profile is `isPrimary = FALSE`, `isActive = TRUE`, `is_hard_deleted = FALSE`; created more than 18 months ago; never used in a transaction or last used in a completed transaction paid more than 24 months ago.
- Soft delete sets `deletedAt` timestamp and `isActive = FALSE`; after 1 day, hard delete permanently removes profiles and sets `dim_account_profile.is_hard_deleted = TRUE`.
- Push notification sent once per schedule before cleanup; CTA redirects to Saved Passenger Data page (template code: `member_automate_profile_cleanup`).
- Notice on Saved Passenger Data page informs users that unused profiles may be automatically deleted.

## Details
**PRD :** [Automated Cleanup for Unused Passenger Profiles](https://borobudur.atlassian.net/wiki/x/jYGnFQE)

**Figma** : [\[SSoT\] Passenger Data](https://www.figma.com/design/pmjLVou57fGZ0FJLPOmPLt/-SSoT--Passenger-Data?node-id=2740-71650&t=loljDFH5YK2Ibgv0-4)

1. System runs a scheduled job every 30 days to identify unused profiles in `members_profile_b2c` with criteria:

    1. B2C account

        1. `The B2C account of this profile has more than 100 secondary profiles; AND`
        2. `The Profile is marked isPrimary = FALSE; AND`
        3. `The Profile is marked isActive = TRUE ; AND`
        4. `The profile marked is_hard_deleted = FALSE; AND`
        5. `The profile was created more than 18 months ago; AND`
        6. `(The profile has never been used in any transaction; OR was last used in a completed transaction paid more than 24 months ago.)`

    2. System performs **soft delete**:

        1. `deletedAt` is filled with timestamp
        2. `isActive = FALSE`

    3. After 1 day, system performs **hard delete**:

        1. Profiles with `deletedAt IS NOT NULL` and `isActive = FALSE` are permanently deleted
        2. `dim_account_profile.is_hard_deleted = TRUE`

2. System sends push notification to users in the segment before cleanup:

    1. Sent once per schedule
    2. CTA redirects to Saved Passenger Data page

3. System displays a notice on Saved Passenger Data page:

    1. Informs users that unused profiles may be automatically delete

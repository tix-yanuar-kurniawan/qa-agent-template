# PLAT-53933 — [BE] UMP - Improving Manual SMS/WA Template Whitelist
> **Related:** [[UNM-3330]]

## PRD Summary

Adds a whitelist toggle (ON/OFF) to the SMS/WA template detail view on the UMP
dashboard. When ON, the template skips the blacklisting mechanism. A new
privilege WHITELIST_SMS_WA controls who can see and use the toggle (granted to
message approver role). All toggle actions require popup confirmation and
generate audit log entries with timestamp, IP, user ID, template name, entity
name, event type, and success/fail result.

## Key Learnings

- The audit log table in the PRD defines 7 fields x 2 event types.
- The PRD says "confirmation first before set": dismissing the popup leaves the
  state unchanged.
- The PRD does not require blacklist removal before whitelisting a template.

## Summary

This story covers a backend solution for automated cleanup of profiles. The approach uses a direct BigQuery query to identify targeted profiles and performs backend validation before deletion. Validation checks include profile type (primary or secondary), account type (B2C or non-B2C), and whether the profile is already soft or hard deleted.

## Key Points

- Use a direct BigQuery query to identify targeted profiles for cleanup.
- Validate on the backend before deletion.
- Check profile type: primary or secondary.
- Check account type: B2C or non-B2C.
- Check whether the profile is already soft or hard deleted.

# PLAT-53383 — [BE] Disable points redeem for specific affiliate partners
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-53387]]
> **Related:** [[PLAT-53387]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-53383

## Summary

This backend story disables points redemption on the payment page for orders with a restricted `tag_aff_id`. When payment passes a restricted affiliate ID to Loyalty, the points redemption section shows a 0 points state, the toggle/input is disabled, and a customized capping tooltip is displayed. Backend configuration requires setting the restricted `tag_aff_id` and mandatory tooltip copy in EN and ID.

## Key Points

- Trigger: user opens payment page and payment passes a restricted `tag_aff_id` to Loyalty.
- Points redemption section shows 0 points state; toggle/input is disabled.
- Capping tooltip shows a customized message for the 3rd-party restriction.
- BE config: set `tag_aff_id` where redemption is restricted (e.g. `6ZERJ59PJY9R4VP8`).
- Mandatory tooltip copy: EN — "You cannot use points because you've received an exclusive deal for this order."; ID — "Kamu nggak bisa pakai poin karena kamu dapet harga eksklusif untuk pesanan ini."

## Details
**GIVEN**

* There have been points redemption restrictions set for a specific `tag_aff_id`

**WHEN**

* The user opens the payment page
* AND Payment passes to Loyalty that the order has a `tag_aff_id` restricted for points redemption

**THEN**

* The points redemption section will show **0 points state**
* AND the points redemption toggle/input will be **disabled**
* AND the capping tooltip will appear, showing a **customized message** for that 3rd-party restriction

### Additional Details

1. **In the BE config, we will need to set:**

    1. `tag_aff_id`  where points redemption will be restricted

        1. Example: `6ZERJ59PJY9R4VP8`

    2. Tooltip copy for the `tag_aff_id`  (Mandatory)

        1. EN: You cannot use points because you’ve received an exclusive deal for this order.
        2. ID: Kamu nggak bisa pakai poin karena kamu dapet harga eksklusif untuk pesanan ini.

# PLAT-54054 — [Panel] Add additional fields in Mission Config for integration with Discovery 
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-54052]]
> **Related:** [[PLAT-54052]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-54054

## Summary
This Panel story adds Homepage Banner fields to mission config for Discovery integration. New Section Config includes Section ID, Banner Image (EN and ID), and Visibility dropdown (Login, Non-login, Both). Mission dashboard improvements include making Live preview and Steps sections sticky and enabling search for Vertical and Payment method.

## Key Points
- Homepage Banner Section Config adds Section ID field.
- Banner Image fields for EN and ID locales.
- Visibility dropdown options: Login, Non-login, Both.
- Mission dashboard: make Live preview and Steps sections sticky.
- Enable search for Vertical and Payment method in mission dashboard.

## Details
In the mission config, we will need to add: Homepage Banner

1. Section Config

    1. Section ID

2. Banner Image

    1. EN
    2. ID

3. Visibility (dropdown)

    1. Login
    2. Non-login
    3. Both

4. Mission improvement:

    1. Make 2 section on the mission dashboard sticky

        1. Live preview
        2. Steps

    2. Enable search for:

        1. Vertical
        2. Payment method

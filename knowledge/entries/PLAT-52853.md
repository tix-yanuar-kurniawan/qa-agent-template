# PLAT-52853 — [BE] Handle PNV Status Failed Retrieval & Retry (RabbitMQ & Kafka)
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-52850]]
> **Related:** [[PLAT-52850]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-52853

## Summary

For asynchronous Loyalty processes (RabbitMQ or Kafka) triggered by event-driven or batch workflows that require PNV status, failed PNV retrieval for a specific user or message must be retried using existing RabbitMQ/Kafka retry mechanisms per message/per user. If retry succeeds, processing continues; if exhausted, the message fails gracefully without blocking others. All consumers must be idempotent, with configurable retry settings and observable failed messages.

## Key Points

- Retry uses existing RabbitMQ/Kafka retry mechanism when PNV status retrieval fails.
- Retry is per message/per user, not per batch.
- If retry succeeds, processing continues normally; if exhausted, message fails gracefully without blocking others.
- Consumers covered include Release OnHold Refund Point, Benefit Tier Upgrade (Cobrand), Vertical Tier Upgrade, Free Tier Upgrade, Release Lock Point, Save Earn Point, Inject Unverified Points after user PNV on payment success page (Kafka), Earn Point External – Claim BPG, ULP Refund Point, ULP Finalize Lock Point, Migrate Pending Points to ULP.
- Retry configuration (attempts, delay) is configurable; all consumers must be idempotent.
- Failed messages are logged and observable; no manual intervention required for transient PNV failures.

## Details
**GIVEN**
An asynchronous Loyalty process (RabbitMQ or Kafka) requires PNV status
And the process is triggered by event-driven or batch workflows

**WHEN**
PNV status retrieval fails for a specific user or message

**THEN**

* The system retries using the **existing RabbitMQ / Kafka retry mechanism**
* Retry is handled **per message / per user**, not per batch
* If retry succeeds, processing continues normally
* If retry is exhausted, the message fails gracefully without blocking others

### Scope (Consumers Covered)

* Release OnHold Refund Point (RabbitMQ)

* Vertical Tier Upgrade (RabbitMQ)
* Free Tier Upgrade (RabbitMQ)

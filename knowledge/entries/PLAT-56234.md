# PLAT-56234 — Mission Dashboard Improvements: Duplicate mission & Section Background
> **Related:** [[PLAT-45655]] · [[PLAT-34075]] · [[PLAT-56197]] · [[PLAT-56232]] · [[PLAT-56233]] · [[PLAT-57096]] · [[PLAT-53429]]

## PRD Summary
Admins can **duplicate** an existing mission from the Mission List; Mission Creation opens with all eligible fields pre-filled except **Mission Slug**, **Start Date**, and **End Date** (left empty). Saving creates a **new** mission without changing the original. Separately, **section background** (Image or Solid Color) is stored at **Section ID** level: create/update of any mission under that Section ID can overwrite the background, and the **most recently updated** value is the source of truth for all missions sharing that Section ID. Builds on Mission Dashboard [[PLAT-45655]].

## Key Learnings
- Duplicate is a **copy-into-create** flow, not an in-place clone: three fields intentionally blank (slug, start, end).
- Section background is **section-scoped**, not mission-scoped for display: latest write wins across all missions with the same Section ID (example: Mission A Image @ 1 Jan, Mission B Solid Color @ 5 Jan → both show Solid Color).
- Platforms: Backend (PLAT-56197 section mapping; PLAT-56232 Duplicate BE marked Invalid), Panel - dWeb (PLAT-56233 Duplicate), Multi-Platform QA (PLAT-57096).

# PLAT-54035-v2 — [General] Top Spender Improvement Development
> **Related:** [[PLAT-52883]] · [[PLAT-54034]] · [[PLAT-54037]] · [[PLAT-54038]] · [[PLAT-54040]] · [[PLAT-55085]] · [[PLAT-55284]] · [[PLAT-55684]] · [[PLAT-56187]]

## PRD Summary
This epic covers improvements to the already-developed Top Spender gamification program. The improvements include: (1) Challenge/Mission system with automatic progression tracking (GBV, order count, room nights) and multiple reward types, (2) Campaign Dashboard for Game Masters with vertical configuration, special partner management, and challenge CMS, (3) Notification system with rank drop (tiered by position), monthly checkpoints, and new challenge alerts, (4) Pending orders pagination fix for >25 orders, and (5) Non-winner raffle and consolation rewards.

## Key Learnings
- Challenges are AUTOMATICALLY active within date range - no user 'Start' click needed (updated requirement)
- Multiple challenges can run simultaneously with independent dates
- Challenge retroactive logic: only if user joined during challenge timeframe
- Rank drop notifications are TIERED: 1-20 immediate, 21-200 daily 9AM, 200+ weekly Monday 9AM
- Retroactive invitation notification: daily 10AM cron, once per user only
- Challenge rewards configurable via CMS: Fixed Amount OR Earn Rate + Multiplier
- UI shows combined coins from challenges + special partners (no individual icons)
- PLAT-55284 (Leaderboard Sorting) was marked Invalid

**Q: More info on the non-Top-200 raffle?**
Source of truth = PRD §4.9 "Final Announcement and Reward Distribution". After the leaderboard freeze (11:59:59 PM Jul 28 2026) → audit pending/refunded → Game Master "verify winners" toggle (auditing → complete), non-winner rewards form a **3-tier structure**:

2. **Raffle (non-Top-200):** a lucky draw with a **separate prize list/pool**, distinct from the Top 200 grand prizes.
3. **Remaining users:** all remaining (non-raffle-winning) users receive product vouchers.
- GV/promo codes are injected into the user's "My Voucher" section (actual code shown). Data ingested to DWH within 2 weeks (needs BI DWH dev).

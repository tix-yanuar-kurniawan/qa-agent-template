# PLAT-53931 — [QA] Test: Disabling Points Redemption & Earning for Transaction from specific affiliate partners
> **Type:** Story · **Status:** Done · **Priority:** Medium · **Parent:** [[PLAT-53387]]
> **Related:** [[PLAT-53387]]
> **Jira:** https://borobudur.atlassian.net/browse/PLAT-53931

## Summary

This QA story creates and executes a comprehensive test plan to validate that points earning and redemption are correctly disabled for transactions from specified affiliate partners. Coverage includes backend logic, frontend UI states, tooltip messages, and verification that normal transactions and other partner flows are unaffected. Edge cases include mixed cart scenarios, users with zero points, and partner configuration changes.

## Key Points

- Validate points earning and redemption are correctly disabled for specified affiliate partner transactions.
- Verify backend logic, frontend UI states, and tooltip messages.
- Ensure normal transactions and other partner flows are unaffected.
- Cover edge cases: mixed cart scenarios, user with zero points, partner configuration changes.

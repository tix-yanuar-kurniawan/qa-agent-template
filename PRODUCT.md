# Product

## Register

product

## Users
QA Engineers and Developers using Claude Code (or Cursor / Antigravity) to automate test case creation and analysis. They operate in a fast-paced environment and need a reliable, local interface to manage their test case generation and analysis workflow.

## Product Purpose
To provide a simple, local queue UI for processing test case requests: the UI only queues them, and the agent fulfils them when it runs `/run-it`. It bridges the gap between manual requirements and automated test case generation, enabling efficient QA workflows and standardized output for tools like TestRail.

## Brand Personality
Efficient, Precise, Reliable. The tool should feel like a professional utility—a "workhorse" that is dependable, fast, and stays out of the way of the primary task.

## Anti-references
Cluttered SaaS dashboards with unnecessary metrics, "hero-metric" templates, and over-complicated navigation. Avoid the "AI-generated" look of warm-neutral/cream backgrounds, identical card grids, and violet neon gradients or glow. Colour should carry meaning (request type, status, priority), not decorate.

## Design Principles
1. **Utility First**: Every element should serve a clear functional purpose in the queue management workflow.
2. **Clarity over Decoration**: Prioritize readable typography and clear status indicators over visual flourishes.
3. **Reliability through Feedback**: Provide immediate and clear feedback for all user actions (adding to queue, file uploads, status changes).

## Accessibility & Inclusion
WCAG AA compliance, high contrast for readability, and clear focus states for keyboard navigation. Support for reduced motion and screen readers.
